# 第6段階 専門確認・公開承認：構造化設計と実装記録（v15）

作成日：2026-10-19。汎用の独立業務試作。実際の組織的承認・法的判断の代替にならない。

## 目的と責務の分離

1. 科学的専門家は自らの分野、原資料、確認対象版を明示して科学上の論点を確認する。
2. 編集者は原稿の構成、文章、媒体ごとの整合を扱い、専門的指摘の採否・差分を記録する。
3. 権利及び個人情報の確認担当は素材単位・利用態様単位で適用条件、リスク及び相談先を記録する。
4. 公開判断者は現実に授権された範囲で承認、保留、差戻し、不承認を判断し、承認対象版・条件を特定する。
5. 配信担当者は承認版と公開版を照合し、公開時点の操作と状態を記録する。

- 各手順のAI_ASSISTは提案・照合候補の支援までに限定し、外部AIへの機微情報入力を自動で許可しない。

## 設計上の重要な論点

- チェックリストの「適合」は法的な適法性や組織決裁の証拠にならない。
- 科学的指摘がないことは完全性、真実性、社会的な無害性の証明にはならない。
- 公開申請書と実際の決裁を区別する。`DocumentInstance`に記入しても`ReviewDecision`の存在や真性は自動成立しない。
- 条件付き判断は「承認」と一括変換せず、条件達成・再評価・再承認の必要性を記録する。
- 権利確認は資料・素材・利用媒体・改変・配信範囲に依存する。著作権と肖像等の他の権利を一括しない。
- 法令の適用、個人情報取扱主体、情報の類型と利用条件について個別の確認を行う。
- 標準、倫理、手順はすべて独立の提案として版管理し、実運用における規程との関係は未確認とする。
