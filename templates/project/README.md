# Project Templates — Source Guidance

Project instance scaffolding is now generated by `script/init_project.py` from `core/workflows/eight_stage.json` (without copied rule files). This folder is reserved for future **versioned, editable templates** of project-specific task artifacts and checklist layouts. No such approved templates have been authored.

Project-specific `AGENTS.md` and `CLAUDE.md` are generated as lightweight context adapters referring to shared policies and stage guidance; they must not duplicate diverging policy texts or grant approval rights.
