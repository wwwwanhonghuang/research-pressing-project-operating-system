# 企画・編集方針の正本データ

このフォルダは、6件の業務タスク、6件の手順、3件の業務標準案、2件の倫理指針案、およびハンドブック構成定義を格納する。記載事項はいずれも独立した草案であり、特定組織の公式規程を表さない。

- `tasks/`: 入力、成果物、担当、完了確認および各定義への参照
- `procedures/`: 実施手順、記録する成果、例外の扱い
- `knowledge/`: 編集判断の規範・倫理上の参照内容
- `recipes/`: 出版物の構成定義。知識データの複製を避ける

ハンドブックは `make stage-01-handbook` で組み立てる。プロジェクトの実行・判断の記録はこれらの定義とは別の場所で保管する。
