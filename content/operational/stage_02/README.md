# Stage 2: 事前調査・資料収集

Eight task definitions, eight SOPs, five quality standards, three ethics guidance entries and one handbook composition recipe. The definitions are independently authored drafts. They are rendered into a TeX/PDF handbook and a website-neutral JSON view.

## Research outputs

調査計画、検索履歴、資料台帳、方法要約、数値確認、研究史と異説、主張・根拠対応表、引継ぎ記録。

## Commands

`make stage-02-handbook`, `python script/compose_handbook.py --recipe content/operational/stage_02/recipes/PUB-RES-HANDBOOK.json --output build/handbooks/stage_02 --stem stage-02-handbook`.
