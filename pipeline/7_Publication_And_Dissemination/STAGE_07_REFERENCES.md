# Stage 7 external references and scope

- SRC-RFC-9110: https://www.rfc-editor.org/rfc/rfc9110.html
  - RFC 9110 HTTP Semantics。HTTP応答の技術的意味に限る。公開内容の正確性や許諾の規範ではない。
- SRC-WCAG22: https://www.w3.org/TR/WCAG22/
  - WCAG 2.2 W3C Recommendation。適用する達成基準は媒体と契約・規程の範囲に従い定める。
- SRC-W3C-MEDIA: https://www.w3.org/WAI/media/av/
  - W3C WAIの動画・音声アクセシビリティ指針。法的義務の一律の根拠ではない。
- SRC-PPC: https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/
  - 個人情報保護委員会の通則ガイドライン。具体的な適用関係は確認を要する。
- SRC-JPA: https://psych.or.jp/jpamember/press_release_guidelines/
  - 日本心理学会のプレスリリース指針。科学的発信の参考であり他分野の全組織を拘束しない。

参照先は法令適用又は内部承認の代替とはならない。具体的な要求事項は対象媒体と適用関係によって定める。
