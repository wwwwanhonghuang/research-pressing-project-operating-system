# 企画・編集方針 — タスク定義

次の6件は `content/operational/stage_01/tasks/` にある版管理済みの定義を参照します。実行時はプロジェクト個別の記録を作成してください。

- `TSK-PLN-INTAKE` — 企画依頼の受理と対象範囲の設定
- `TSK-PLN-TOPIC` — 企画候補の探索・比較と暫定選定
- `TSK-PLN-AUDIENCE` — 読者・利用場面と情報アクセスの分析
- `TSK-PLN-ANGLE` — 編集上の問い・主張範囲と証拠状態の整理
- `TSK-PLN-FORMAT` — 媒体構成・制作工程・資源見積り
- `TSK-PLN-GATE` — 企画書統合・レビューと調査段階への引継ぎ
